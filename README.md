# Around The U.S.

## Project Description

Around The U.S. is an interactive web application developed during Sprint 8 of the TripleTen Web Development Program.

The project allows users to edit profile information, create new location cards, like cards, delete cards, and view enlarged images in modal windows. The main goal of this project was to practice JavaScript fundamentals, DOM manipulation, event handling, reusable functions, and dynamic rendering of content using HTML templates.

## Features

- Edit profile information through a modal form.
- Automatically populate form fields with current profile data.
- Generate cards dynamically from an array of objects.
- Create new cards through the "New Place" form.
- Delete cards from the page.
- Like and unlike cards.
- Open images in a dedicated image preview modal.
- Close modals using dedicated close buttons.
- Render content dynamically using HTML templates.
